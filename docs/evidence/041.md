## Behavior / resource matrix

The full matrix is §2–§6 of [../m7-adapter-contract.md](../m7-adapter-contract.md):
current legacy behavior inventory (metadata/domain/UEL operations, `value_field`,
`key_filter`, `n_rows`, `threads`, projection, batch source), compatibility
requirements, intentional exclusions, special-value/acronym conversion policies,
backend selection, schema/dictionary modes, batch ownership, cancellation, error
propagation, repeated scans, and the end-to-end resource envelope with concrete
caps (256 MiB library root / 512 MiB OS process cap, ≤ 4 descriptors, bounded
queues and per-worker stacks, noncollecting-sink acceptance recipes at ≥ 4× the
OS cap).
