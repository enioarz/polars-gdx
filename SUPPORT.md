# Support

* **Usage questions** — open a [GitHub discussion](https://github.com/enioarz/polars-gdx/discussions)
  or a GitHub issue with the `question` label.
* **Bug reports** — open a [GitHub issue](https://github.com/enioarz/polars-gdx/issues)
  with a minimal reproducer (see [CONTRIBUTING.md](CONTRIBUTING.md)).
* **Security issues** — report privately as described in
  [SECURITY.md](SECURITY.md).
